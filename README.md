# projection-space

Интерактивная демонстрация трёхмерной модели **(время t, вектор v, запрос q)** с тремя ортогональными **проекциями** на координатные плоскости и переключением **ракурса камеры** (метафора «эмоционального» взгляда на ту же точку).

## Запуск

```bash
cd projection-space
npm install
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173`).

## Сборка

```bash
npm run build
npm run preview
```
